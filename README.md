# 🚀 Project Overview

This project uses Python-based web scraping techniques to extract product/book information from websites.

The scraper collects:
- 📚 Product/Book Names
- 💰 Prices
- ⭐ Ratings

The extracted data is stored in CSV format for further analysis.
